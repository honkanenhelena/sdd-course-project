The application needs to have the possibility to add expenses with the data being: Amount spend, date, category of purchase, option to select it as a necessity, option for a note. The application then must present these expenses in a way where the user can edit and delete expenses. The expenses should be presented in a way where they can be filtered by date, category and necessity, and the application needs to have a monthly summary available with a breakdown of the expenses. To help the user cut costs the application needs to have a possibility to set a monthly budget for categories which also shows how close the user is to said budget. The application needs to validate the input that the user gives it, so that no false dates or negative numbers can be inserted, and it also needs to enforce the necessary field for the data. The data that exists in the application must also be saved and be consistent so that the application can be used on a monthly basis. The application also needs to have a separate spending chart where the different categories can be visualized.
